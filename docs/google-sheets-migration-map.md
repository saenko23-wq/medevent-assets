# Мапа міграції Google Sheets -> MedEvent CRM

Джерело: `2026 Календарний план MedEvent – копія`

## Вкладки та модулі

| Google Sheets | Модуль платформи | Що переноситься |
| --- | --- | --- |
| `План_продажів` | План продажів, угоди, календар заходів | Річний план/факт, компанії, продакти, менеджери, напрямки, суми й кількість слотів по кожному заходу |
| `Оплати_Комісії` | Оплати, бонуси, фінансовий контроль | Статус погодження, сума продажу, CRM-джерело, планова дата звіту, очікувана/фактична оплата, статус оплати, бонуси менеджерів, коментарі |
| `Дедлайн звітів` | Операційні задачі заходу | DocLink, сторінка, МОЗ/ТЦ, розсилка, аналітика, звіт клієнту, звіт через 6/12 місяців, блокери, наступний відповідальний |
| `Довідники` | Довідники | Dropdown-значення: статуси, пакети, менеджери, формати, гонорари, типи подій, компанії, продакти, напрямки, спікери, препарати, Event ID |
| `Пакети участі` | Пакети | Ціни, формати, тривалість, склад сервісів для Standart / Plus / Mono / Combo |
| `🎓...` окремі вкладки заходів | Сторінка заходу | Паспорт події, бюджет, сторінка, драфт програми, трансляції, програма, партнери, безфарм-рядки, гонорари, теми, препарати, коментарі |
| `ДОКУМЕНТИ` | Документи | Посилання, типи документів, власники, нотатки |
| `Курси`, `ЕК`, `МЖП` | Курси / освітні продукти | Дані курсів, платформи, реєстрації, освітні картки після детального імпорту |

## Реалізовано в поточному коді

- Загальний календар `/calendar`
- Повна сторінка кожного заходу `/events/[id]`
- Програма та партнери як `EventSlot`
- Операційні дедлайни як `OperationTask`
- Розширювані довідники `/references`
- Матриця пакетів `/packages`
- Документи та посилання на сторінці заходу
- Ролі й read-only режим для `viewer`

## Наступний крок для повної міграції

Потрібен імпорт усіх рядків із Google Sheets у PostgreSQL:

1. Прочитати всі вкладки заходів `🎓...` і створити `Event` + `EventSlot`.
2. Нормалізувати клієнтів, продактів, спікерів, препарати й напрямки через довідники.
3. Перенести `Оплати_Комісії` у `Deal`, `Payment` і бонусні поля.
4. Перенести `Дедлайн звітів` у `OperationTask`.
5. Перенести посилання з `ДОКУМЕНТИ`, `Курси`, `ЕК`, `МЖП` в окремі модулі курсів/документів.
6. Зберегти технічні ключі з таблиці для дедуплікації та перевірки імпорту.
